# Tutorials

Guided lessons that take you from a fresh checkout to a running agent. Follow them in order the first time; each builds on the previous one.

| Tutorial | You'll learn |
|---|---|
| [Getting started](getting-started.md) | Install dependencies, create a user, and start SheetBot. |
| [Your first task](your-first-task.md) | Create a task, run an agent, and watch the task complete. |
| [Setting up other agents](setting-up-other-agents.md) | Run Deno, Python, and Bash agents. |
| [Using API keys for agents](using-api-keys-for-agents.md) | Create a scoped key and run an agent without a password. |
| [Working with sheets](working-with-sheets.md) | Write task results into a sheet and view them in the UI. |
| [Customizing your sheet](customizing-your-sheet.md) | Choose a widget for each sheet column in SQLite. |
| [Publishing a read-only sheet](publishing-a-sheet.md) | Share a dashboard without requiring a login. |
| [Working with artefacts](working-with-artefacts.md) | Upload task outputs and use S3-style buckets. |
| [Writing a library script](writing-a-library-script.md) | Turn a script into a reusable task template. |
| [Building a custom widget](building-a-custom-widget.md) | Render a sheet column with your own Web Component. |

When something does not work, see [Debug a failed task](../how-to/debug-failed-tasks.md), [Troubleshooting](../how-to/troubleshoot.md), or the [reference](../reference/index.md).
