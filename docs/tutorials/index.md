# Tutorials

Guided lessons that take you from a fresh checkout to a running agent. Follow them in order the first time; each builds on the previous one.

| Tutorial | You'll learn |
|---|---|
| [Getting started](getting-started.md) | Install dependencies, create a user, and start SheetBot. |
| [Your first task](your-first-task.md) | Create a task, run an agent, and watch the task complete. |

When something does not work, see [Troubleshooting](../how-to/troubleshoot.md) or the [reference](../reference/index.md).
